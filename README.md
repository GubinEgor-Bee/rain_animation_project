## Описание проекта
Программа визуализирует анимацию падающего дождя. Реализован 3D-эффект: капли на дальнем плане двигаются медленнее, они меньше в размерах и более темные, что создает ощущение глубины. Также добавлена возможность регулировки плотности дождя в реальном времени.

## Функциональные возможности
### Основной функционал
- Непрерывная генерация падающих капель.
- 3D-эффект и имитация перспективы.
### Дополнительный функционал
- Интерактивный ползунок для настройки плотности генерации капель.

## Требования к системе
- **Python:** 3.9 или выше
- **Операционная система:** Windows / macOS / Linux
- **Библиотеки:** `tkinter` (встроенная)
